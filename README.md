# RuruRules

サーバーへの初回参加時に、ルールの確認と同意を求める Folia 26.3 向けプラグインです。同意するまで、移動、チャット、ブロック操作などを制限します。

## 動作環境

| 項目 | バージョン |
|---|---|
| サーバー | Folia 26.3（`folia-api 26.3.build.6-alpha` でビルド） |
| Java | 25 以上 |

## 機能

- **行動制限**: ルールに同意するまで、次の操作をブロックします。
  - 移動（視点移動は可能）
  - ブロック破壊・設置
  - アイテムのドロップ・拾う操作
  - インベントリのクリック・ドラッグ
  - チャット送信（近距離チャットのプラグインにも流れません）
  - コマンド実行（`/rules` 関連を除く）
  - エンティティやブロックとのインタラクト
- **Web からのルール取得**: 設定した URL の HTML を解析し、ゲーム内の「本」として表示します。サイトの対訳表で、プレイヤーの言語に翻訳します。ページは定期的に取得し直すので、サイトを更新すれば本にも反映されます。
- **チャットフォールバック**: 本の表示が無効なときや取得に失敗したときは、チャットに URL と同意ボタンを表示します。取得に失敗しても前回の内容を使い続け、5 分後にやり直します。
- **再表示**: 制限された操作をすると、ルールを再表示します（3 秒に 1 回まで）。
- **本の開き直し**: 同意せずに本を閉じると、もう一度開きます。同意済みの人が `/rules` で読み返すときは開き直しません。

### 本の開き直しの仕組み

本を閉じてもクライアントはサーバーへ何も送らないので、閉じたことは直接には分かりません。本を開いている間はマウスで視点を動かせず、移動キーも効かないので、次のどれかが起きたら閉じたと判断して開き直します。

- 視点を動かす
- 移動キーやジャンプキーを押す
- クリック、ホットバーの切り替え、アイテムを捨てる、チャットなどの操作をする

閉じたあと何も操作しなければ、本は閉じたままです。その間も移動やチャットなどの制限は続きます。開き直すと本は 1 ページ目に戻ります。`show-message-on-block: false` にすると開き直しません。

## コマンド

- `/rules`（別名 `/rule`）: ルールを再表示します。
- `/rules agree`: ルールに同意します（本やチャットのボタンから実行されます）。
- `/rules reload`: [管理者] 設定と `lang` フォルダを再読み込みし、ルールページを取得し直します。
- `/rules reset <プレイヤー名>`: [管理者] 同意状態をリセットし、再度同意を求めます。

## パーミッション

- `rururules.admin`: 管理者コマンド（`reload`, `reset`）の実行権限。デフォルトは `op` です。

## 設定

`config.yml` で次の設定ができます。

```yaml
# ルールページのURL（日本語）
rules-url: "https://www.vcmc.jp/rules"

# サイトの対訳表（i18n.js）。日本語のページを各言語に翻訳して本にします。空にすると翻訳しません
translations-url: "https://www.vcmc.jp/i18n.js"

# 言語ごとのルールページのURL。設定した言語は、翻訳の代わりにそのページを使います
rules-urls:
  en: ""
  zh_cn: ""
  zh_tw: ""
  zh_hk: ""

# 本としてルールを表示するか (false にするとチャットにURLを表示するだけ)
show-as-book: true

# 本のタイトル・著者
book-title: "vcmc.jp サーバールール"
book-author: "vcmc.jp"

# HTML取得タイムアウト (ミリ秒)
fetch-timeout-ms: 10000

# ルールページを取得し直す間隔 (分)。0 にすると起動時と /rules reload のときだけ取得します
refresh-interval-minutes: 60

# HTMLから取得するCSSセレクタ (main content エリアを指定)
# 空にすると <body> 全体から取得
content-selector: "main, article, .content, #content"

# 本に載せない要素のCSSセレクタ
exclude-selector: "nav, footer, script, style, noscript, form, button, .nav, .header, .footer, .sidebar, .site-header, .eyebrow, body > header"

# 操作をブロックしたときや、同意せずに本を閉じたときにルールを再表示するか
show-message-on-block: true
```

`translations-url`、`rules-urls`、`refresh-interval-minutes`、`exclude-selector`、`messages` は、以前の `config.yml` に無くても既定値で動きます。

## 多言語対応

プレイヤーのクライアントの言語設定に合わせて、メッセージを自動で切り替えます。ゲーム中に言語を変更すると、次のメッセージから反映されます。

| クライアントの言語 | 表示する言語 | 文面の場所 |
|---|---|---|
| 日本語 | 日本語 | `config.yml` の `messages` |
| English（各地域） | English | `lang/en.yml` |
| 简体中文 | 简体中文 | `lang/zh_cn.yml` |
| 繁體中文（台灣）、文言 | 繁體中文（台灣） | `lang/zh_tw.yml` |
| 繁體中文（香港） | 繁體中文（香港） | `lang/zh_hk.yml` |
| 上記以外 | English | `lang/en.yml` |

コンソールへのメッセージとログは日本語のままです。

`lang` フォルダのファイルは初回起動時に作られます。編集して `/rules reload` を実行すると反映されます。ファイルに無いキーは jar 内の既定の文面を使います。

jar を更新しても、`lang` フォルダのファイルは置き換えません。ただし、以前の既定の文面のまま編集されていないファイルは、起動時に新しい文面へ置き換え、以前のファイルは名前の後ろに `.old` を付けて残します。1.3.0 の `lang/zh_hk.yml`（広東語の文面）がこれに当たります。編集したファイルはそのまま使うので、新しい文面にしたいときは削除して再読み込みしてください。

### ルールページの翻訳

サイトのルールページは日本語で配信され、ブラウザの JavaScript が `i18n.js` の対訳表で各言語に置き換えています。本は JavaScript を実行せずに HTML を読むので、このプラグインが `translations-url` の対訳表を読み、サイトと同じ規則で日本語のページを翻訳してから本にします。

- 対訳表の列は「日本語、English、简体中文、繁體中文（台灣）、繁體中文（香港）」です。香港の列が無い行は台灣の文を使います（サイトと同じ）。
- 要素の中身がまるごと表の日本語と一致するものと、テキストの部分だけが一致するものを置き換えます。空白はまとめてから比べます。
- 表に無い文は日本語のまま表示し、その数をコンソールに出します。サイトの文を変えたら、`i18n.js` の対訳表も同じ文に直してください。
- 対訳表は、ルールページと同じ間隔で取得し直します。取得できないときは、前回の表を使い続けます。一度も取得できていないときは、本の最初のページで翻訳が無いことを案内し、日本語のページを表示します。
- チャットに出すリンクには `?lang=en` のように言語を付けて、サイトをプレイヤーの言語で開かせます。
- `rules-urls` に言語ごとのページを設定すると、その言語だけは翻訳の代わりにそのページを使います。ページは言語ごとに別の HTML にしてください。

## コード構成

- `RuruRulesPlugin`: メインクラス。初期化と各クラス・コマンドの登録を行います。
- `RulesManager`: 同意状態を管理し、`agreed_players.txt` へ保存します。
- `RulesCommand`: `/rules` コマンドとタブ補完。
- `RulesListener`: 未同意プレイヤーの操作をキャンセルします。
- `RulesBookFetcher`: ルールページを非同期に取得して、本を作ります。
- `BookWatcher`: 同意していないプレイヤーが本を閉じていないかを見張り、閉じていれば開き直します。
- `BookCloseDetector`: 本が閉じられたかどうかの判定。サーバーがなくてもテストできます。
- `RulesPageParser`: HTML から本に載せる文章を取り出します。
- `SiteTranslations`: サイトの対訳表（i18n.js）を読み、日本語のページをサイトと同じ規則で各言語に翻訳します。
- `BookLayout`: 文章を本のページに分けます。全角文字が多くても 1 ページに収まるよう、表示幅で判断します。
- `Messages`, `i18n`: 受け取る人の言語で文面を作ります。

## ビルド

Java 25 が必要です。

```
mvn package
```

`target/ruru-rules-<バージョン>.jar` が生成されます。
